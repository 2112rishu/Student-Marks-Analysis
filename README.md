Student Marks Data Analysis Project

Project Description

This project analyzes student marks using Python and NumPy. It reads student information from a CSV file and calculates useful statistics for Maths, Science, and English.

Tools and library used to make this project

. Python 
. Numpy
. CSV module

Data contains in CSV file are  :-

. Name of each student.
. Roll number of each student.
. Maths marks of each student.
. Science marks of each student.
. English marks of each students.

The Statistics that calulated in this project are :-
1. Total marks of each student.
2. Average marks of each student.
3. class average for each subject.
4. Highest and lowest marks of the class.
5. Range.
6. Standard deviation.

The concepts used to make this project are :-
. Variables
. Lists
. Loops
. Functions
. CSV file handling
. NumPy arrays
